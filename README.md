# SV-sentiment-analysis-

## How to run ?

1. create a virtual enviroment 
```bash 
conda create -n sentiment python=3.11 -y 
```

2. activate the sentiment 

```bash 
conda activate sentiment 

```

3. install the requirements 

``` bash 
pip install -r requirements.txt 
```
